# Nightshift Salvage
An original co-op night expedition prototype built with Luau and Rojo 7.7.1.

## Getting Started
To build the place from scratch, use:

```bash
  rojo build -o "NightshiftSalvage.rbxlx"
```

Next, open `ViralSlope.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).
